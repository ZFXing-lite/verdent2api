# 部署文档

把 verdent2api 跑起来。它代理的是 Verdent **桌面端限免模型**，不是控制台 API key。

## 前置

- Go 1.19+（源码构建；Docker 不需要本机 Go）
- 一个能登录 Verdent 的账号
- 机器能访问 `www.verdent.ai`、`login.verdent.ai`、`llm-proxy.verdent.ai`

## 构建

```bash
git clone https://github.com/ZFXing-lite/verdent2api.git
cd verdent2api
./build.sh
```

产物：

- `bin/verdent-login`：PKCE 登录，写入账号 token
- `bin/verdent-server`：OpenAI 兼容网关

## 登录

```bash
./bin/verdent-login
# 或
./bin/verdent-login -auth ./auths/accounts.json -label main
```

终端会打印登录链接并尝试打开浏览器。登录成功后回调到本机随机端口，token 写入 `auths/accounts.json`。

多账号就换账号再跑一次，同 `user_id` 会覆盖 token，不同账号会追加。

## 配置

```bash
cp config.example.json config.json
openssl rand -hex 24    # 填进 api_key
```

| 字段 | 默认 | 说明 |
|---|---|---|
| `listen` | `:7866` | 监听地址 |
| `api_key` | 空 | 网关密钥。空 = 不鉴权，公网必须设置 |
| `auth_file` | `./auths/accounts.json` | 登录写入的账号文件 |
| `state_file` | `./data/state.json` | 冷却/计数 |
| `catalog_file` | 空 | 模型目录。空则读 `~/.verdent/model-catalog-cache.json`，没有就用内嵌限免列表 |
| `free_only` | `true` | `/v1/models` 只返回限免模型 |
| `upstream.base_url` | `https://llm-proxy.verdent.ai` | 不要改成 `api.verdent.ai`，那条路打不到 Free mode |

环境变量：`V2A_API_KEY`、`V2A_LISTEN`、`V2A_AUTH_FILE`、`V2A_STATE_FILE`。

## 启动

```bash
./bin/verdent-server -config config.json
```

登录工具之后写入的新账号，网关每 15 秒重读一次，不用重启。

### systemd

```ini
[Unit]
Description=verdent2api
After=network.target

[Service]
WorkingDirectory=/opt/verdent2api
ExecStart=/opt/verdent2api/bin/verdent-server -config /opt/verdent2api/config.json
Restart=on-failure
Environment=V2A_API_KEY=你的随机密钥

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now verdent2api
```

### Docker

```bash
docker build -t verdent2api .
docker run -d --name verdent2api -p 7866:7866 \
  -v $PWD/auths:/app/auths \
  -v $PWD/data:/app/data \
  -e V2A_API_KEY=你的随机密钥 \
  verdent2api
```

登录可以在宿主机跑 `verdent-login -auth ./auths/accounts.json`，容器会热重载这个文件。

## 验证

```bash
curl http://127.0.0.1:7866/healthz
curl http://127.0.0.1:7866/v1/models -H "Authorization: Bearer 你的密钥"
curl http://127.0.0.1:7866/status -H "Authorization: Bearer 你的密钥"
```

`/v1/models` 里 `is_free` 为 true 的才是限免。

## 公网

- 必须设置 `api_key`
- 前面加 HTTPS 反代，SSE 要关缓冲：

```nginx
location / {
    proxy_pass http://127.0.0.1:7866;
    proxy_http_version 1.1;
    proxy_set_header Connection "";
    proxy_buffering off;
    proxy_read_timeout 300s;
}
```

`auths/accounts.json` 是登录 token，权限设成 `600`，不要提交进 git。`.gitignore` 已经忽略整个 `auths/`。

## 排障

**503 `no_healthy_account`**：还没登录，或账号都在冷却。看 `/status`。

**401**：网关密钥不对，或上游 token 失效。重跑 `verdent-login`。

**持续 429 / 正文含 20004**：桌面 App 更新了 agent prompt，内嵌 `template.json` 过期。用桌面版抓一条真实请求，替换 `internal/verdent/template.json` 后重新编译。

**模型列表只有两个**：正常。没读到桌面版缓存时用内嵌兜底。装一次桌面版，或自己准备 `catalog_file`。
